# Support guide

## Before requesting support

1. Open **UltraCache Pro > Maintenance** and run the runtime and website checks.
2. Open **Tools > Site Health** and review all UltraCache tests.
3. Export the UltraCache support report.
4. Reproduce the problem with other full-page cache and overlapping CSS/JavaScript optimization features disabled.
5. For checkout problems, test with two separate browser sessions and record whether Classic Checkout or Checkout Blocks is used.

## Include with a report

- UltraCache Pro, WordPress, PHP and WooCommerce versions.
- Hosting/webserver, Redis/APCu and CDN details.
- Exact URL type and user role affected.
- Relevant settings export with secrets removed.
- Reproduction steps, expected result and actual result.
- Browser console/network evidence for interface problems.

The support report intentionally redacts configured secret values. Never send API tokens, database credentials, personal data or complete production logs in a public issue.
