UltraCache Pro 11.4.0 (code fixes)

Bug fixes
- Fixed a fatal error on the front end when "Disable Google Maps" was enabled: the markup-level remover (UCP_Optimizer_HTML_Trait::remove_google_maps_markup) was missing and is now implemented (Google Maps embeds and JS API scripts only; honours data-ucp-keep).
- Fixed a fatal error on the front end when "Disable Google Fonts" was enabled: the markup-level remover (UCP_Optimizer_HTML_Trait::remove_google_fonts_markup) was missing and is now implemented (Google Fonts stylesheet links, font resource hints and @import rules only).
- Fixed a fatal error on the front end when "Lazyload fade-in" was enabled: the missing UCP_Optimizer_Media_Image_Trait::append_class_attribute helper is now implemented (merges with any existing class, idempotent, safe with $ in class values).
- Fixed a fatal error when running the runtime compatibility tests: UCP_Runtime_Tests::run_all() called two undefined methods. test_direct_cache_runtime() and test_headless_renderer_runtime() are now implemented.
- "Clear used CSS" now also clears the file-based used-css-served/ artifacts, matching purge-all.
- Reduced the legacy classic-admin notice renderer to a documented no-op; the React admin already surfaces WP_CACHE and cache-conflict warnings.

Maintenance release
- Improved page-cache key handling so the early drop-in and the WordPress helper use the same URL path rules.
- Removed an unused SSL check in the CDN resource-hint normaliser.
- Added an optional file-based Used CSS delivery mode.
- Added an optional template-based CSS cache scope for sites that can safely share CSS output across matching templates.
- Added an admin-only Asset Inspector for reviewing loaded script and style handles.
- Expanded the default Used CSS safelist for common themes, builders, WooCommerce, consent tools, forms and sliders.

UltraCache Pro 11.2.6

Maintenance release
- Scoped browser cache headers to static assets instead of applying them to every response.
- Long-lived browser cache headers are now limited to content-addressed combined CSS and JavaScript files.
- Added browser cache rules for additional image and font formats.
- Preserved foundational CSS selectors and custom properties during Used CSS processing.
- Aligned cache-control and validator headers between MISS, HIT and fallback responses.

Upgrade note
After updating, purge Used CSS and Critical CSS once so the new CSS output can be rebuilt. Browser-cache rules are refreshed on the next settings save when rule writing is enabled.
