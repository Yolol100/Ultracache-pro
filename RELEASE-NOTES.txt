UltraCache Pro 11.4.11 (safety & clarity pass)

Hardening (no new features, no renames)
- REST action handlers are now wrapped in a last-resort guard: any unexpected exception/fatal is converted into a clean WP_Error ("Probeer het opnieuw of controleer Tools") and logged, instead of surfacing as a bare 500. Handlers keep full control of their own success and WP_Error responses.
- Admin requests now have a client-side timeout (30s default, 90s for preload/CSS/browser-scan/queue/database actions). A stuck request can no longer leave a button on "Bezig…"; it aborts client-side and shows a calm fallback message while any server-side work continues.
- Used/Critical CSS retry limit default lowered from 5 to 3, matching the existing sanitizer fallback and storage rules. Calmer, more predictable generation with the same safe fallback to normal/async CSS.
- No option keys, hooks, REST namespace/slugs, text-domain, class names, cache keys, drop-in policy or wp-config policy were changed.

UltraCache Pro 11.4.0 (code fixes)

Bug fixes
- Fixed a fatal error on the front end when "Disable Google Maps" was enabled: the markup-level remover (UCP_Optimizer_HTML_Trait::remove_google_maps_markup) was missing and is now implemented (Google Maps embeds and JS API scripts only; honours data-ucp-keep).
- Fixed a fatal error on the front end when "Disable Google Fonts" was enabled: the markup-level remover (UCP_Optimizer_HTML_Trait::remove_google_fonts_markup) was missing and is now implemented (Google Fonts stylesheet links, font resource hints and @import rules only).
- Fixed a fatal error on the front end when "Lazyload fade-in" was enabled: the missing UCP_Optimizer_Media_Image_Trait::append_class_attribute helper is now implemented (merges with any existing class, idempotent, safe with $ in class values).

- "Clear used CSS" now also clears the file-based used-css-served/ artifacts, matching purge-all.
- Reduced the legacy classic-admin notice renderer to a documented no-op; the React admin already surfaces WP_CACHE and cache-conflict warnings.
